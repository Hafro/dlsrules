# The length or age of first capture

The function returns the length or age class where catch is at or above
a certain portion of the frequency mode.

## Usage

``` r
dl_1st_capture(x, y, p = 0.5)
```

## Arguments

- x:

  length or age

- y:

  bin count of length or age, normally observed catches

- p:

  the proportion of the modal. 0.5 (the default) is from the ICES bible.

## Value

A vector of lengths or age of first captures
