# Target reference length L_F=M

The target reference length of the fishing pressure proxy of the rfb
rule and of the harvest rate proxy of the chr rule (ICES 2025): L_F=M =
0.75 L_c + 0.25 L_inf, which assumes M/K = 1.5.

## Usage

``` r
target_reference_length(Lc, Linf)
```

## Arguments

- Lc:

  The length at first capture (defined as the length at 50% of modal
  abundance)

- Linf:

  L-infinity from the Von Bertalanffy equation

## Value

Target reference length L_F=M
